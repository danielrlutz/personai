# Archive confirm

Use when the user drops mail, PDFs, or asks to file a document.

1. Prefer the in-app ingest queue (OCR + bulk split). Do not invent filenames, Fristen, or amounts.
2. Naming: `{date}_{DocType}_{Entity}.pdf` (e.g. `2026-08-09_BILL_Swisscom.pdf`).
3. Taxonomy folders 1–10: Official, Housing, Insurance, Financial, Employment, Health, Education, Legal, Misc, Vehicles.
4. Summarize proposed name, folder, Fristen, and duplicates — then wait for **Needs your confirmation** in the app. Never claim the file was archived before confirm.
5. After confirm, local archive always writes under the profile; Drive is optional/soft-gated.
