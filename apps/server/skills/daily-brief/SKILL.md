# Daily brief

When composing or explaining the morning brief:

1. Prefer structured app data (briefing API / live ops): Fristen (7d), recent archive, ledger/money moves, pending confirms, CEO profile.
2. Format: short bullets. Highlight any Frist due within 36h first.
3. If nothing material changed, say so briefly — do not invent urgency.
4. Never invent deadlines, amounts, or calendar events. Calendar is optional when linked.
